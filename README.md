# Foreigners in Poland Assistant Android App

A portfolio Android demo application designed for foreigners living in Poland.

The app provides a bilingual Russian/English interface and includes basic informational features for foreigners, such as residence permit information, an AI-powered legal-style Q&A assistant, and a simple Polish language learning chatbot.

## Features

- Bilingual interface: Russian and English
- AI-powered Q&A assistant for legal-style questions
- Basic information about residence permit application in Poland
- Simple chatbot for learning Polish
- Mobile UI built in Android Studio

## Tech Stack

- Android Studio
- Java / Kotlin
- Android SDK
- OpenAI API integration
- XML layouts
- Mobile app architecture basics

## Main Screens

- Home screen
- Legal-style Q&A assistant
- Residence permit information section
- Polish learning chatbot
- Language switch / bilingual content

## Project Status

This is a portfolio/demo project created to practice Android development, AI API integration, and building useful tools for foreigners in Poland.

## Disclaimer

This app is for educational and portfolio purposes only.  
It does not provide real legal advice.
